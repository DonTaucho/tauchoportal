Option C: Implementation Details

✓ Advantages

  • Keeps pages logically separate (good for structure)
  • Minimal changes to current UI
  • Clear navigation between related pages
  • Mini-widgets show context without full page load
  • Quick links prevent users from getting lost

✗ Disadvantages

  • Still feels disconnected (two separate pages)
  • User must navigate between pages to complete workflow
  • Status info must be kept in sync (duplication risk)
  • Managing brand AND devices feels like multiple steps
  • Doesn't reduce cognitive load much vs. current

User Flow Example

User wants to add new LIFX device:
1. Currently on Devices page
2. Sees "LIFX not connected" in Brand Status widget
3. Clicks "Connect New Brand" → goes to Brand Settings
4. Clicks "Connect" for LIFX → enters credentials
5. Gets link "Go to Devices" after connecting
6. Back on Devices page → clicks "+ Add Device" → selects LIFX device
